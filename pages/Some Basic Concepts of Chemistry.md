# Scientific Notation
	- $8008 = 8.008 * 10^3$
	- $43216  = 4.3216 * 10^4$
	- $0.0025 = 2.5 * 10^{-3}$
- # Significant Figures
- **What are significant figures?** #card
	- Meaningful digits which are known with certainity
	  * All non-zeroes are significant
	- Examples:
		- $285 = 3$
		- $0.0012 = 2$
		- $0.03 = 1$
		- $500.0 = 4$
		- $2.0034 = 5$
		- $0.200 = 3$
		- $125000 = 3$
